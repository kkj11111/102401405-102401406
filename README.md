# 校园失物招领（WEB 版）

基于第一次结对作业原型实现的“校园失物招领”网页应用：学生可以集中发布寻物 / 招领信息，按物品名称等关键词搜索，查看物品详情与发布者联系方式，并在物品找回 / 归还后由发布者更新状态，减少重复询问与无效联系。

- 技术栈：原生 HTML + CSS + JavaScript（无任何框架、无后端、无外部 CDN 依赖），数据存储在浏览器 localStorage
- 兼容性：使用 **谷歌浏览器（Chrome）** 打开 `index.html` 即可运行

---

## 一、功能一览

| 功能 | 说明 |
| --- | --- |
| 浏览信息 | 首页按「全部 / 寻物 / 招领」及物品类别（证件卡类 / 电子设备 / 钥匙饰品 / 生活用品 / 其他）筛选浏览 |
| 发布寻物信息 | 选择“寻物”，填写物品名称、丢失地点、联系方式等 |
| 发布招领信息 | 选择“招领”，填写拾取地点等信息 |
| 搜索物品 | 按物品名称、地点、描述、昵称关键词搜索，支持寻物 / 招领筛选 |
| 查看物品详情 | 展示类别、地点、描述、发布时间、发布者昵称与联系方式 |
| 联系发布者 | 一键复制联系方式 |
| 修改信息状态 | 发布者可将信息标记为「已找到 / 已归还」，详情页与首页列表同步显示；我的发布中可重新开放 |
| 我的发布 | 集中管理自己发布的信息：按类型 / 状态筛选、标记、删除 |

## 二、目录结构说明

```
校园失物招领WEB/
├── index.html          # 唯一入口：打开即可使用（SPA，hash 路由切换五个页面视图）
├── css/
│   └── style.css       # 全部样式（蓝白配色、卡片、表单、徽标、弹窗、toast）
├── js/
│   ├── core.js         # 数据层核心纯函数（创建/校验/过滤/状态更新/删除/统计/时间格式化）
│   ├── storage.js      # 数据持久化（localStorage 读写、种子数据、搜索历史）
│   └── app.js          # 视图渲染与交互（路由、五个页面、事件委托）
├── test/
│   ├── core.test.js    # 核心函数单元测试（20 个用例）
│   └── storage.test.js # 存储层单元测试（9 个用例）
└── README.md           # 本文档
```

说明：

- **为什么是 SPA 单入口**：只有一个 `index.html`，其他同学下载全部文件后，用谷歌浏览器打开 `index.html` 即可看到完整应用，页面之间通过 `#/` hash 切换，不需要依次打开多个 html 文件。
- **为什么拆成 core / storage / app 三个 JS 文件**：把纯逻辑（core）与存储（storage）从页面渲染（app）中分离，逻辑层不依赖 DOM，可以直接被 Node 单元测试复用（`module.exports` + 浏览器 `window` 双端导出）。

## 三、使用说明（测试人员参考）

### 1. 运行应用

1. 下载 / 克隆本仓库全部文件；
2. 使用**谷歌浏览器**（Chrome）双击打开 `index.html`；
3. 首次打开会自动生成 8 条演示数据（校园卡、钥匙、雨伞、耳机等），可直接体验浏览、搜索、发布、状态修改。

### 2. 体验核心流程

- **浏览 / 搜索 → 详情 → 联系**：首页浏览卡片 → 点击卡片查看详情 → 点击“一键复制联系方式”；
- **发布 → 成功**：底部“发布” → 选择寻物 / 招领 → 填写表单 → “立即发布” → 发布成功页；
- **更新状态**：详情页“标记为已找到 / 已归还”（弹窗确认）→ 首页与搜索列表同步显示“已找到 / 已归还”徽标；也可在“我的发布”中标记、重新开放或删除。

### 3. 运行单元测试

```bash
# 需要 Node.js（>= 18，推荐 20+）
node --test
```

全部用例通过时输出 `pass 29 / fail 0`。

### 4. 数据重置

清除浏览器该站点 localStorage（开发者工具 → Application → Local Storage → 删除 `clf_items_v1` 与 `clf_search_history_v1`），刷新页面即可重新生成演示数据。

## 四、设计说明（简版）

- **数据流**：用户操作 → `app.js` 调用 `core.js` 纯函数处理 → `storage.js` 读写 localStorage → 重渲染视图。
- **状态闭环**：信息只有 `open`（进行中）与 `done`（已找到 / 已归还）两种状态；`done` 由发布者从详情页或我的发布页触发，写入后所有页面读取同一条数据，自动同步展示。
- **表单校验**：发布前校验类型、物品名称（≤30 字）、地点（必填）、联系方式（手机号 / QQ / 邮箱 / 微信号格式），错误逐字段提示。
- **XSS 防护**：所有用户输入经 `esc()` 转义后再插入页面。
